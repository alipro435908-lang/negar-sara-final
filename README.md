# نگار سرا

سایت استودیوی خدمات خلاقانه (طراحی، عکاسی، کارگردانی هنری) شامل:

- صفحه‌ی اصلی با طراحی اختصاصی، معرفی خدمات و فرم ثبت سفارش
- وبلاگ با صفحه‌ی اختصاصی برای هر پست و لینک قابل اشتراک‌گذاری (کپی لینک، اشتراک‌گذاری بومی گوشی، تلگرام، واتس‌اپ)
- پنل مدیریت با ورود امن برای دیدن و مدیریت سفارش‌ها و انتشار/ویرایش/حذف پست‌های وبلاگ

این یک اپلیکیشن واقعی Node.js است (نه فقط فایل‌های استاتیک HTML)، چون پنل مدیریت و ذخیره‌ی سفارش‌ها نیاز به یک سرور دارد که اطلاعات را نگه دارد.

## اجرای سایت روی کامپیوتر یا هاست

۱. Node.js نسخه‌ی ۱۸ به بالا نصب کن.
۲. داخل پوشه‌ی پروژه این دستور را بزن:

```
npm install
```

۳. سپس سایت را اجرا کن:

```
npm start
```

۴. سایت روی آدرس `http://localhost:3000` بالا می‌آید.

## ساختار پروژه

```
negar-sarabsazi/
├── server.js          فایل اصلی سرور و مسیرها (routes)
├── db.js              کمک‌تابع خواندن/نوشتن فایل‌های JSON
├── data/
│   ├── posts.json     یادداشت‌های وبلاگ
│   ├── orders.json    سفارش‌های ثبت‌شده
│   └── admin.json     نام کاربری و رمز عبور پنل مدیریت
├── views/              قالب‌های EJS صفحات
└── public/
    ├── css/style.css   طراحی و رنگ‌بندی سایت
    └── js/
```

اطلاعات (سفارش‌ها و پست‌ها) به‌صورت ساده در فایل‌های JSON داخل پوشه‌ی `data` ذخیره می‌شوند. برای یک سایت با ترافیک بالا، بهتر است این بخش را به یک دیتابیس واقعی (مثل MongoDB یا PostgreSQL) تبدیل کنی، اما برای شروع کاملاً کار می‌کند.

## آپلود روی هاست / دیپلوی آنلاین

چون این یک اپلیکیشن Node.js است، باید روی سروری اجرا شود که از Node.js پشتیبانی می‌کند، نه هاست‌های استاتیک ساده. چند گزینه‌ی متداول:

- **Liara** یا **ابرآروان** (هاست‌های ایرانی که Node.js را پشتیبانی می‌کنند)
- **Railway** یا **Render** (بین‌المللی، رایگان برای شروع)
- یک VPS با Node.js نصب‌شده و اجرای دائمی با ابزار `pm2`

نکته: چون داده‌ها در فایل‌های JSON روی دیسک سرور ذخیره می‌شوند، هاستی انتخاب کن که فضای ذخیره‌سازی آن پایدار باشد (بعضی هاست‌های رایگان با هر دیپلوی جدید فایل‌ها را پاک می‌کنند).

## تغییر متن‌ها و رنگ‌بندی

- متن خدمات: در فایل `server.js` داخل آرایه‌ی `SERVICES`
- رنگ‌بندی سایت: در فایل `public/css/style.css` بالای فایل، بخش `:root`
- نام و لوگوی متنی سایت: در فایل‌های `views/*.ejs`، عبارت «نگار سرا»

## اشتراک‌گذاری پست‌ها

هر پست یک آدرس اختصاصی دارد، مثلاً:
`https://yourdomain.com/post/raz-e-noor-e-tabii`

این لینک را می‌توان مستقیم برای هرکسی فرستاد، در تلگرام/واتس‌اپ به اشتراک گذاشت، یا با دکمه‌ی «اشتراک‌گذاری بومی» گوشی (در مرورگرهای موبایل) ارسال کرد.
